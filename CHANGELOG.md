# Changelog

All released versions, newest first. A release is a push to `main` that changes the version in `package.json`; the release workflow builds the image and creates the tag and GitHub release.

## v0.1.0 - 2026-11-13
**Short:** Add backup importer, WebDAV upload and viewer
**Long:** First release (P-1): imports SMS Backup & Restore files from an inbox or WebDAV upload, de-duplicates and verifies every message and attachment, and shows the archive as chats with photos, search and stats. Read-only.
